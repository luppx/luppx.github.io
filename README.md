# Su Lu’s homepage

Personal academic homepage at <https://luppx.github.io/>, built with Jekyll and the [AcadHomepage template](https://github.com/RayeRen/acad-homepage.github.io).

## Preview locally

With Ruby 3.3 and Bundler installed, run:

```sh
bundle install
bash run_server.sh --livereload
```

Open <http://127.0.0.1:4000/>. Edit `_pages/about.md` for the homepage, `_data/navigation.yml` for section links, and `_config.yml` for profile details.
